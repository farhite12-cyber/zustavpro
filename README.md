# Зустов Про

Розничный магазин: ремонт телефонов, ремонт электроники и компонентная пайка
(планшеты, наушники, колонки), замена батареек в часах. Товарная матрица — своя
и партнёрская: то, чего нет на полке, отгружается со склада партнёра.

Поток клиентов: постоянные по сарафанному радио плюс случайные прохожие.

## Цель

Интернет-магазин и одностраничный сайт в одном, чтобы рекомендация стала ссылкой,
ассортимент партнёров стал виден, а потоки «ремонт» и «товар» замкнулись друг на друга.

## Сайт

Рабочая вёрстка лежит в [`site/`](site/) — 6 страниц, без сборки и зависимостей.

| Файл | Назначение |
|---|---|
| `site/data/content.js` | **Единственный файл, который нужно править.** Цены, услуги, каталог, контакты, отзывы |
| `site/varianty.html` | **Страница выбора** — три варианта главной рядом, с превью |
| `site/index.html` | Вариант А «Мастерская» — ставка на компетенцию |
| `site/index-b.html` | Вариант Б «Прайс» — ставка на цену и скорость ответа |
| `site/index-c.html` | Вариант В «Личный мастер» — ставка на доверие и сарафанное радио |
| `site/remont-telefonov.html`, `site/elektronika.html`, `site/chasy.html` | Страницы услуг |
| `site/katalog.html`, `site/kontakty.html` | Каталог и контакты |
| `site/assets/style.css`, `style-b.css`, `style-c.css` | Стили трёх вариантов |
| `site/assets/app.js` | Подстановка данных, форма, фильтр прайса |

Всё незаполненное записано как `⟨заглушка⟩` и подсвечивается на сайте жёлтым.
Когда данные будут настоящими — поставить `DRAFT: false` в начале `content.js`,
и полоса «черновик» сверху исчезнет.

Посмотреть локально:

```
python3 -m http.server 8788 --directory site
```

Форма заявки работает без сервера: собирает текст и открывает Telegram
с готовым сообщением.

## Решения

- **Платформа сайта — Tilda** (конструктор). Партнёрских прайсов в электронном виде нет,
  наличие уточняется звонком, импортировать нечего — значит конструктор ни в чём не проигрывает,
  а сайт правится своими силами.
- **Полноценный интернет-магазин на старте не делаем.** Вместо него кураторская витрина
  на 30–100 позиций плюс запрос «привезём за 1–3 дня» на всё остальное.
- **Сайт обещает не наличие, а скорость ответа** — 15 минут. Это обещание можно держать.

## Статус

Собраны три варианта главной — открыть `site/varianty.html` и выбрать.
Внутренние страницы услуг и каталога пока оформлены по варианту А.

Сайт ждёт данных: прайс услуг по трём группам, адрес и ориентиры,
рабочие контакты, год начала работы, первые позиции каталога, тексты отзывов.
Всё это заполняется в одном файле `site/data/content.js`.
