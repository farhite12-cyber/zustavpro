# Zustav PRO

«Тут есть Всё!» — магазин и мастерская в ТЦ «Мобильный Павильон», Сущёвский Вал 5 стр. 12,
павильоны П72–П73, м. Савёловская. Ежедневно 10:00–20:00.

**Продажа:** телефоны всех марок, ноутбуки и ПК, часы (кварц, механика, электроника, Garmin,
смарт), наушники и колонки (JBL, Marshall, Яндекс), бытовые товары Xiaomi, аксессуары
Baseus / MOMAX / Anker / WIWU, батарейки и аккумуляторы, запчасти, защитные стёкла,
гидрогелевые плёнки, чехлы. Новая и Б/У техника, опт и розница.

**Услуги:** ремонт телефонов, ноутбуков, компьютеров, часов, наушников и колонок,
фотоаппаратов, мелкой бытовой техники и очков; компонентная пайка; изготовление ключей
(дверные, сейфовые, домофонные, автомобильные); пульты для шлагбаумов, ворот, сигнализаций
и ТВ; замена батареек; плёнка и стёкла; ксерокопия.

## Сайт

Интернет-магазин в фирменных цветах логотипа: фиолетовый `#470A4A`, зелёный `#4C8C06`,
оранжевый `#C2611C`. Статика без сборки, шрифты Jost + Onest.

| Файл | Назначение |
|---|---|
| `site/data/shop.js` | **Единственный файл для правок.** Контакты, категории, товары, услуги, отзывы |
| `site/index.html` | Главная: витрина, категории, услуги, отзывы |
| `site/katalog.html` | Каталог с поиском и фильтром по категориям |
| `site/uslugi.html` | Услуги: ремонт, ключи и пульты, быстрые услуги |
| `site/kontakty.html` | Контакты и карта |
| `site/assets/shop.css` | Фирменный стиль |
| `site/assets/shop.js` | Отрисовка данных, поиск, фильтры |

Незаполненное записано как `⟨заглушка⟩` и подсвечивается оранжевым.
Когда каталог станет настоящим — `DRAFT: false` в начале `shop.js`.

Посмотреть локально:

```
python3 -m http.server 8788 --directory site
```

## Корзина, заказы и панель менеджера

| Страница | Что делает |
|---|---|
| `site/korzina.html` | Корзина и оформление заказа |
| `site/zakazy.html` | Заказы клиента со статусом |
| `site/crm.html` | Панель менеджера: сводка, фильтры, смена статусов, клиенты |
| `site/assets/store.js` | Слой хранения: местный режим или общая база |
| `site/data/config.js` | Ключи Supabase — единственное, что надо заполнить |
| `supabase/schema.sql` | Таблица, правила доступа и функции для базы |

Пока `config.js` пуст, сайт работает в местном режиме: заказы лежат в браузере клиента,
менеджеру не видны. Как только появятся ключи — переключается на общую базу сам.

### Подключение Supabase — четыре шага

1. **Завести проект** на supabase.com → New project. Регион — Frankfurt.
2. **Создать таблицу:** SQL Editor → New query → вставить всё из `supabase/schema.sql` → Run.
3. **Вписать ключи** в `site/data/config.js`: Project Settings → API →
   `Project URL` и ключ `anon` / `publishable`.
   Ключ `service_role` в код не попадает никогда — он даёт полный доступ к базе.
4. **Завести менеджеров:** Authentication → Users → Add user, почта и пароль.
   Свободной регистрации нет, посторонний в панель не войдёт.

### Как устроена защита

- Клиент без входа может только **создать** заказ — читать таблицу ему нельзя,
  иначе он увидел бы чужие заказы и телефоны.
- Свой заказ клиент смотрит через функцию `zp_order_status`: она отдаёт строку,
  только если совпали и номер заказа, и телефон. Телефон сравнивается по цифрам,
  поэтому `+7 900…` и `8 900…` — одно и то же.
- Менеджер после входа видит и правит все заказы.
